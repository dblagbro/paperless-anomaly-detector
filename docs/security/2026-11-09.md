## Reproduce

Build from a clean git archive to exclude ignored data and secrets:

```sh
revision=$(git rev-parse HEAD)
context=$(mktemp -d)
git archive "$revision" | tar -x -C "$context"
docker build --label org.opencontainers.image.source=https://github.com/dblagbro/paperless-anomaly-detector --label org.opencontainers.image.revision="$revision" -t anomaly-security:candidate "$context"
python3 tools/offline_checks.py --image anomaly-security:candidate --output /tmp/anomaly-check-unique-output
trivy image --image-src docker --scanners vuln --severity HIGH,CRITICAL --format json --output /tmp/anomaly-scan.json anomaly-security:candidate
```

The offline runner tests code from the exact image and archives its revision's tests. It disables networking, supplies a generated synthetic token, uses disposable SQLite state and retains logs. Use a new output directory for each attempt. Never run this suite inside a production container.

Regenerate locks in Linuxamd64/CPython3.11 using `pip install --dry-run --ignore-installed --report`, retaining the complete graph and each archive's SHA256. Validate a new image before deployment. OS repository updates can change, so repeat builds are not claimed byte-for-byte identical.
